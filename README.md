## ✨ Features

- **Premium UI/UX:** Inspired by Linear, Vercel, and Stripe. Features glassmorphism, smooth animations, and a dark/light mode toggle.
- **Fully Responsive:** Optimized for mobile, tablet, and desktop screens.
- **Performance Optimized:** Semantic HTML, minimal CSS, and vanilla JavaScript for lightning-fast load times.
- **SEO Ready:** Proper meta tags, Open Graph integration, and semantic structure.
- **Interactive Elements:** Scroll reveal animations, tilt effects, magnetic buttons, and an infinite testimonial marquee.
- **Complete Pages:** Home, About, Services, Projects, Pricing, Contact, and Legal pages.

## ️ Tech Stack

- **Frontend:** HTML5, CSS3 (Custom Properties, Flexbox, Grid), Vanilla JavaScript (ES6+)
- **Fonts:** Fraunces, Inter, JetBrains Mono (via Google Fonts)
- **Deployment:** Vercel
- **Version Control:** Git & GitHub
